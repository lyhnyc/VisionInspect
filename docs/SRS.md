# SRS —— IC 封装视觉检测系统（软件需求规格 · 1页版）

## 1. 背景与目标

半导体封装测试产线中，分选机/AOI 需要在极短节拍内完成芯片外观检测：
引脚缺陷（划痕/缺失/污点）、标记完整性、外形尺寸。本系统为该场景的
桌面级完整实现，用于验证算法、软件架构与工程化能力。

**模拟客户**：某封测厂分选机改造项目（下称"客户"）。

## 2. 范围

| 做 | 不做 |
|---|---|
| 1 工位、1 相机（模拟/海康双实现）、灰度检测 | 多机联动、彩色成像、3D 检测 |
| BLOB 缺陷、模板定位、卡尺测量、标记 OCR/DMC | 引线键合内部检测 |
| TCP 上报（MES 语义）、串口触发（PLC 语义） | 完整 MES 对接 |
| Windows 上位机 + C++ 算法库 | Linux 部署（架构预留） |

## 3. 功能需求

| ID | 需求 | 优先级 |
|---|---|---|
| F1 | 相机连接/软触发取图，断线自恢复 | 高 |
| F2 | 定位：输出 (dx, dy, θ) + 置信度 | 高 |
| F3 | 缺陷检测：面积可配，输出框/面积/粗分类 | 高 |
| F4 | 测量：卡尺亚像素边缘对 + 距离 | 高 |
| F5 | 标记检测：OCR + DMC 解码 + 残缺/错位判定 | 中 |
| F6 | 判级分档：OK/NG/RETRY，记录入库 | 高 |
| F7 | 统计：良率、缺陷帕累托、CSV 导出 | 中 |
| F8 | TCP 服务：心跳/远程触发/结果上报 JSON | 中 |
| F9 | 串口：PLC 触发/复位 | 低 |
| F10 | DL 复核通道：anomalib ONNX 推理，融合判级 | 中 |

## 4. 非功能需求

| ID | 指标 | 验证方式 |
|---|---|---|
| N1 | 视觉节拍 ≤120ms/颗（2048² 灰度） | 流水线压测分解表 |
| N2 | 亚像素精度 <0.1px | 合成图真值（test_caliper） |
| N3 | 缺陷检出率 ≥99%（合成缺陷集）/ 误检 ≤1%/图 | 合成缺陷批测 |
| N4 | 连续运行 ≥1h 无内存泄漏无崩溃 | VS 诊断 + 日志 |
| N5 | 算法异常不崩溃，降级 RETRY | 故障注入 |

## 5. 验收口径（与"客户"对齐）

- "缺陷"定义：面积 ≥30px² 且对比度 ≥15 灰阶的异常区域（写入配方，可调）
- 判级以传统算法为主判，DL 为复核（NG 可申诉重判）
- 所有指标按上表验证方式出具测试报告
